## 推荐阅读路径

1. 先看 [Guides（指南）](./guides/README.md) 建立方法框架。
2. 需要执行步骤时看 [Playbooks（操作手册）](./playbooks/README.md)。
3. 复盘与踩坑经验看 [Lessons（经验教训）](./lessons/README.md)。
4. 查模板、术语和索引看 [References（参考资料）](./references/README.md)。
