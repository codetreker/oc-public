# AGENTS.md - oc-public（外部公开知识库）维护规范

`~/.openclaw/oc-public` 是对外公开知识库。

## 目标

- 发布可公开的知识、经验教训、模板与方法。
- 保持知识结构清晰、导航可用、内容可复用。

## 隐私与安全硬规则（必须）

- 禁止写入任何真实个人隐私信息：姓名、账号、ID、联系方式。
- 禁止写入任何密钥与敏感信息：token、password、api key、内部地址、内部链接。
- 禁止写入客户/内部私有项目细节与未公开信息。
- 如有不确定，默认不发布。

## 内容边界

- 允许：通用方法、公开经验、匿名化模板、去标识案例。
- 禁止：可回溯到个人/组织/项目真实身份的信息。
- 来源若来自 `oc-shared`，必须先完成脱敏和抽象化。

## 导航维护要求

- 根目录 `README.md` 只作为知识库入口与导航，不放细则。
- 规则类内容统一放在 `AGENTS.md` 与 `PRIVACY-RULES.md`。
- 各子目录 `README.md` 负责本目录索引，并能回链根目录。

## 提交规范

- 有效变更后执行 `git add + commit + push`。
- 每次变更后检查导航可用（无死链）。
- commit message 要能说明改动意图。
